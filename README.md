# milhamh95-web

Personal website / blog for milhamh.com.

Built with [Astro](https://astro.build), Tailwind CSS, and Markdown/MDX. Deployed to Cloudflare Workers.

See [plan.md](./plan.md) for the build plan, and [DESIGN.md](./DESIGN.md) for the design system.

## Commands

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start local dev server at `localhost:4321` |
| `npm run build` | Build production site to `./dist/` |
| `npm run preview` | Preview the build locally |
